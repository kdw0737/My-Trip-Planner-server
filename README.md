# 📣 소개
여행 계획을 세우기 힘드신가요? <br>
마이 트립 플래너를 사용해보세요! <br>
일정을 지도로 한눈에 보여줍니다!<br>
또한, 사람들과 일정을 공유하고 소통하며<br>
나에게 맞는 계획을 세워보세요!🚀🚀
